WITNESSONE · MVP v0.8.2

One plug. Every asset. Certified. WitnessONE is the Equinix commissioning toolbox for factory witness tests: plug your laptop into the test network, pick the asset from the device library (or discover it), watch it live in 3D, run the Level-1 script, and walk out with a signed certificate.

This MVP — 5 asset templates: VERTIV XDU1350B CDU · Delta UPS125 · ABB Emax2 LV breaker · DX Unit Type 3 · Schneider PM8000 meter. Each is a versioned JSON template (identity + Equinix points list + 3D layout + test script). Pick one on the connect screen; the twin, tiles, tests & certificate adapt automatically.

Production path: the UI binds to TOP Server v7.1 (Modbus TCP/IP Ethernet driver → OPC UA opc.tcp://localhost:49380) via its Configuration API; the SPL imports as tag CSV. Quality codes shown are OPC (GOOD 192 / BAD 24).

References: Vertiv XDU1350B install/O&M guides (SL-71308/71309/70619), ASHRAE 127-2020 CDU rating, ASHRAE Gl 0 / 1.1 commissioning, OCP L2L CDU test methodology.

On the TOP Server machine: ① Administration tray icon → Settings → Configuration API → Enable = Yes  ② note the port (HTTPS example 57418; HTTP optional)  ③ CORS Allowed Origins = *  ④ HTTPS: open the API URL in a browser tab once and trust the self-signed certificate  ⑤ restart the runtime after changes.
